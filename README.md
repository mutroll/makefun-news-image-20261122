# Sunday 22 November 2026 — The World in One Image

A newspaper-style poster that sums up the world news of Sunday 22 November
2026 in a single 1024x1024 image, drawn entirely in code by `main.py`
(Python 3.13 standard library only — no fonts, no image assets, no network).

The six stories, all of which happened or were first reported on 22 November
2026:

1. **COP31, Antalya** — climate talks near a final deal as a new package is unveiled.
2. **Hong Kong** — polls open for the Election Committee (856 candidates, 723 seats).
3. **Myanmar** — a magnitude 4.1 earthquake strikes in the early hours of Sunday.
4. **Israel** — Yashar and Likud coalition talks open to break the government deadlock.
5. **Las Vegas** — the Formula 1 Grand Prix races today, Verstappen on pole.
6. **Dubai** — the Icons of Porsche festival opens.

## Run it

```sh
python3 main.py
# writes entry.png into $MAKEFUN_OUTPUT_DIR (default /output)
```

The output is deterministic: two runs produce byte-identical PNGs.
